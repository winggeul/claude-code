# 일자별 DB 수량 대시보드

`통합고객목록` 에서 수집한 데이터를 일자·주차·월 단위로 집계해 보여주는 화면.
협력점해피콜은 집계에서 제외한다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 대시보드 본체. 외부 라이브러리 없이 단독 동작 |
| `sample_data.json` | 화면 확인용 샘플 (실제 데이터 아님) |

## 동작

`index.html` 은 같은 폴더의 `data.json` 을 읽는다. 없으면 내장된 샘플로 그리고
상단에 "샘플 데이터" 표시가 붙는다. 실제 데이터가 들어오면 표시가 "실제 수집 데이터"로 바뀐다.

## data.json 형식

```json
{
  "generated": "2026-08-21T03:00:00",
  "excluded": ["협력점해피콜"],
  "rows": [
    { "date": "2026-08-01", "channel": "유튜브-PPL", "count": 5 }
  ]
}
```

하루 × 유입경로 한 줄. 20 일치라도 수백 줄이라 파일 하나로 충분하다.
**개인정보(이름·전화번호)는 넣지 않는다.** 화면에 필요한 것은 건수뿐이므로
집계 단계에서 떨어내면 대시보드가 개인정보를 일절 다루지 않게 된다.

## 배치

시놀로지 NAS 의 Web Station 웹 루트에 `index.html` 과 `data.json` 을 두면 사내에서 접속된다.
`data.json` 은 수집기가 매일 덮어쓴다.

## 유입경로 묶기

화면에는 `유튜브-PPL(5504)` 처럼 코드가 붙어 나온다. **괄호 앞까지를 묶음 이름으로** 쓰고
원본 값은 `channel` 에 그대로 둔다. 대시보드가 묶어서 보여주고, 경로를 누르면 코드별로 펼친다.
`SOOP-PPL(1919)봉준★` 처럼 코드 뒤에 꼬리표가 붙는 경우가 있어 첫 `(` 를 기준으로 자른다.

## 협력점해피콜 제외

유입경로가 아니라 **분류코드 대분류** 값이다. 목록에는 분류코드 칸이 없으므로 집계 단계에서
거를 수 없다. `통합고객목록` 의 **`고객제외조건` 탭**에서 분류코드로 제외한 뒤 검색해야 한다.
즉 제외는 수집 시점에 끝나고, `data.json` 에는 이미 빠진 상태로 들어온다.
