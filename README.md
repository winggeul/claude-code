# CRM4enterprise 데이터 자동 수집

원투원솔루션(OtOSolution)의 `CRM4enterprise` 에서 고객·상담 데이터를 자동으로
뽑아내기 위한 작업 저장소.

## 조사 결과

설치된 PC 에서 확인한 사실:

| 항목 | 값 |
|---|---|
| 실행 파일 | `C:\Program Files (x86)\OtOSolution\CRM4enterprise\CRM4enterprise.exe` |
| 로컬 DB 파일 | **없음** (`.mdb` / `.sdf` / `.sqlite` 전부 미발견) |
| 로컬 설정 파일 | `CRM4enterprise.exe.config` 한 개뿐 |
| 원격 연결 | `211.253.10.23:22443`, `211.253.10.48:63443` (ESTABLISHED) |
| 공개 API | 없음 (벤더 문서·다운로드 페이지 전수 확인) |

`211.253.10.x` 대역은 벤더 웹서버(`otosolution.com` = `211.253.26.37`)와 같은
사업자 할당 대역이다. 즉 **데이터는 PC 가 아니라 벤더 서버에 있고**, 클라이언트는
비표준 포트의 자체 프로토콜로 그걸 받아 화면에만 뿌린다.

따라서 파일을 읽거나 DB 에 붙는 방식은 불가능하다. 남는 경로는 두 개다.

## 경로 A — 벤더 API (정공법, 진행 권장)

엔터프라이즈 계약 건이므로 원투원솔루션에 DB 스키마 또는 연동 API 제공을 요청한다.
승인되면 그 규격에 맞춰 수집기를 새로 작성한다. 가장 안정적이지만 벤더 응답에 의존한다.

## 경로 B — 화면 자동화 (벤더 협조 없이 가능)

`CRM4enterprise` 는 .NET WinForms 앱이라 UI Automation 으로 화면의 표를 그대로
읽을 수 있다. 라이선스 보유자가 자기 화면을 자동으로 넘겨보는 것이므로 프로토콜
역분석과 달리 문제 소지가 없고, 작업 스케줄러에 걸면 무인 수집이 된다.

### 1단계: 화면 구조 조사

```powershell
pip install -r tools/requirements.txt
python tools\crm4_inspect.py
```

`CRM4enterprise` 를 띄우고 **고객목록 화면을 연 상태**에서 실행할 것.
UI 트리 전체를 텍스트 파일로 저장하며, `>>> GRID 발견` 으로 표시된 컨트롤이
데이터가 실제로 들어있는 표다.

옵션:

- `--max-depth N` 탐색 깊이 (기본 8)
- `--grid-rows N` 표 미리보기 행 수 (기본 3)
- `--out PATH` 저장 경로

### 2단계: 수집기 작성

1단계 덤프에서 확인된 `auto_id` / `control_type` 를 기준으로 페이지 이동과
행 추출을 구현한다. 덤프 결과를 받은 뒤 진행.

아직 돌려보지 못했다. 1단계 실행 결과에 맞춰 수정이 필요할 수 있다.
