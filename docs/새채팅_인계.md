### 아직 안 한 것 — Vercel

**Hobby → Hobby 는 프로젝트 Transfer 가 안 됩니다.** Vercel 문서상 "옮겨받을 팀의
멤버여야" 하는데 Hobby 는 로그인이 하나뿐이라 서로의 멤버가 될 수 없습니다.
그래서 회사 계정에 **새로 만드는 방식**으로 갑니다. 이 프로젝트는 Vercel 에 남아 있는
상태가 상담사 인원 숫자 두 개뿐이라 새로 만들어도 잃는 게 없습니다.

매크로 PC 에서 할 일 (사람이 직접):

```powershell
cd C:\CRM자동화\site
npx.cmd vercel logout
npx.cmd vercel login          # 회사 Hobby 계정으로
Remove-Item .\.vercel -Recurse -Force -ErrorAction SilentlyContinue
npx.cmd vercel link --yes --project woori-db-dashboard
npx.cmd vercel deploy . --prod
```

그다음 Vercel 대시보드에서 Storage → Create Database → **Blob**,
Access **Private** 그대로, **`Add a read-write token env var to this connection` 체크**,
Connect Project. 마지막으로 토큰 발급해서 매크로 PC 환경변수 교체:

```powershell
[Environment]::SetEnvironmentVariable("VERCEL_TOKEN", "새토큰", "Machine")
```

  `.gitignore` 의 `dist/` 에 걸려 저장소에 올라간 적이 없습니다. 7월 1일부터의 모든
  숫자가 이 파일 하나에 있고 **날아가면 복구 불가**입니다. 절대 덮어쓰지 마세요.
- **지난 날짜를 다시 수집하면 안 됩니다.** 통합고객목록은 다시 뽑을 때마다 그 사이
  상담사가 수정한 값이 반영돼 다른 날과 기준이 어긋납니다. 그래서 수집기는 항상
  "어제 하루만" 받고 빠진 날을 저절로 메우지 않습니다. 끊긴 날은 영영 못 채웁니다.
- **원본 CSV(`C:\CRM자동화\raw\`)에는 고객 이름과 전화번호가 있습니다.** 집계 후 자동
  삭제되지만, 남아 있는 것을 발견해도 채팅에 올리면 안 됩니다. 숫자가 필요하면
  `store.json` 을 쓰세요 — 건수만 들어 있습니다.
- 이 저장소에는 **GitHub Actions 가 없습니다.** 배포는 매크로 PC 가 Vercel CLI 로 합니다.
- 화면을 고쳐 달라고 하면 **완성된 HTML 파일도 같이 주세요.**
